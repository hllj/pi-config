feat(subagent): whole-workflow token budget nudge

Implements Gap 4 of IMPROVEMENT-PLAN.md: run_workflow gets an optional
budgetTokens (workflowBudgetTokens on the subagent tool's workflow
mode) - input+output+cache summed across steps. At 60%/85% usage, one
advisory steer each names the remaining budget and the next ready
step; the workflow itself is never stopped by this.

Chose tokens over a time-based budget since per-step/per-agent
timeoutMs already covers the wall-clock dimension - tokens was the
uncovered one, matching pi-subagents' "goal missions" idle-turn nudge
this gap was modeled on.

workflow-engine.ts: WorkflowStepResult.usage (input/output/cache per
step), WorkflowState.budgetTokens/budgetNudgesSent, and three pure
functions (totalWorkflowTokens, nextBudgetThresholdCrossed,
formatBudgetNudge) - 16 new unit tests via
npm run test:subagent:workflow-budget. index.ts threads result.usage
into each step's WorkflowStepResult and calls maybeSendBudgetNudge
after every step/parallel-group commit in executeWorkflowSteps.
